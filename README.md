
### Aquiperto ###
![logo](https://github.com/user-attachments/assets/17a947dd-98ef-4d57-809f-1045282e775b)



### Descripiton ###
- A mobile app that uses gps to find the nearest shops or vendors in the area you are in.

  
### Features ###
- The app was developed using java and it connects to a firebase where the data is stored in json format.
- The users can register/login using google auth api, while not required for searches, its required for registering a new location(shop/vendor/service) if the user want to register their bussiness in the catalog.
- The search engine filter the location by address and then displays some reslts in the area. Those can be viewed individually, displaying their info and the map.
- Android studio IDE.
